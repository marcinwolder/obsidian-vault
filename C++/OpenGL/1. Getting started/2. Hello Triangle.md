#### Budowa
Pipeline składa się z kilku obiektów:
1. **VBO** (Vertex Buffer Object) - Punkt wejściowy dla danych do wyświetlenia.
```cpp
float vertices[] = {
	-0.5f, 0.5f, 0.0f,
	-0.75f, -0.5f, 0.0f,
	-0.25f, -0.5f, 0.0f
};

unsigned int VBO;
glGenBuffers(1, &VBO);
glBindBuffer(GL_ARRAY_BUFFER, VBO);
glBufferData(GL_ARRAY_BUFFER, sizeof(vertices), vertices, GL_STATIC_DRAW);
```
2. **VAO** (Vertex Array Object) - Zestaw atrybutów takich jak wskaźniki do atrybutów VBO, ustawienia konfiguracyjne atrybutów, włączenie/wyłączenie atrybutów vertex (`glEnableVertexAttribArray` lub `glDisableVertexAttribArray`).
```cpp
unsigned int VAO;
glGenVertexArrays(1, &VAO);
glBindVertexArray(VAO);
glVertexAttribPointer(0, 3, GL_FLOAT, GL_FALSE, sizeof(float) * 3, (void *)0);
glEnableVertexAttribArray(0);
```
3. **EBO** (Element Buffer Object) - Pozwala na renderowanie obiektów bazując na indeksach vertexów. Używane w połączeniu z VBO.
```cpp
unsigned int indices[] = {
	0, 1, 3,
	1, 2, 3
};

unsigned int EBO;
glGenBuffers(1, &EBO);
glBindBuffer(GL_ELEMENT_ARRAY_BUFFER, EBO);
glBufferData(GL_ELEMENT_ARRAY_BUFFER, sizeof(indices), indices, GL_STATIC_DRAW);
```

##### Wartości parametru `usage` w `glBufferData`

| Nazwa             | Jak często dane są zapisywane? | Jak często dane są odczytywane?   |
| ----------------- | ------------------------------ | --------------------------------- |
| `GL_STREAM_DRAW`  | Jednokrotnie                   | Jednokrotnie (maks. kilkukrotnie) |
| `GL_STATIC_DRAW`  | Jednokrotnie                   | Wielokrotnie                      |
| `GL_DYNAMIC_DRAW` | Wielokrotnie                   | Wielokrotnie                      |
#### Shadery
Shadery są opisane używając języka [[GLSL]].
Aby zbudować najprostszy program, wymagane są dwa shadery:
1. **Vertex Shader**
```cpp
const char *vertexShaderSource = "#version 410 core\n"
	"layout (location = 0) in vec3 aPos;\n"
	"void main() {\n"
	"    gl_Position = vec4(aPos.x, aPos.y, aPos.z, 1.0);\n"
	"}\0";

unsigned int vertexShader;
vertexShader = glCreateShader(GL_VERTEX_SHADER);
glShaderSource(vertexShader, 1, &vertexShaderSource, NULL);
glCompileShader(vertexShader);
```
2. **Fragment shader**
```cpp
const char *fragmentShaderSource = "#version 410 core\n"
"out vec4 FragColor;\n"
"void main() {\n"
"    FragColor = vec4(1.0f, 0.5f, 0.2f, 1.0f);\n"
"}\0";

unsigned int fragmentShader;
fragmentShader = glCreateShader(GL_FRAGMENT_SHADER);
glShaderSource(fragmentShader, 1, &fragmentShaderSource, NULL);
glCompileShader(fragmentShader);
```
#### Program Shaderów
Po poprawnej kompilacji shaderów należy połączyć je w program:
```cpp
unsigned int shaderProgram;
shaderProgram = glCreateProgram();
glAttachShader(shaderProgram, vertexShader);
glAttachShader(shaderProgram, fragmentShader);
glLinkProgram(shaderProgram);

// Usunięcie shaderów po ich zlinkowaniu jest możliwe i wskazane
glDeleteShader(vertexShader);
glDeleteShader(fragmentShader);
```
### Znormalizowane Koordynaty Urządzenia
Podając koordynaty możemy używać wartości od -1.0 do 1.0. Te wartości zostaną automatycznie przeliczone na odpowiednie wartości pikseli bazując na rozmiarze viewportu (`glViewport`).
### Rysowanie
Po skompilowaniu programu shaderów oraz stworzeniu VBO i VAO (oraz opcjonalnie EBO) można przystąpić do rysowania.
#### Rysowanie używając VBO
```cpp
glUseProgram(shaderProgram);
glBindVertexArray(VAO);
glDrawArrays(GL_TRIANGLES, 0, 3); // 3 - ilość rysowanych vertices
```
#### Rysowanie używając EBO i VBO
```cpp
glUseProgram(shaderProgram);
glBindVertexArray(VAO);
glDrawElements(GL_TRIANGLES, 3, GL_UNSIGNED_INT, 0);
// 3 - ilość rysowanych vertices
// GL_UNSIGNED_INT - typ indeksów w indices
```
