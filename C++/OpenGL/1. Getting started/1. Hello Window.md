### Setup
```cmake
find_package(OpenGL REQUIRED) # Znalezienie zainstalowanej biblioteki OpenGL

include(FetchContent)

FetchContent_Declare(glfw GIT_REPOSITORY https://github.com/glfw/glfw.git GIT_TAG 3.5.1)

set(GLFW_BUILD_EXAMPLES OFF CACHE BOOL "" FORCE)
set(GLFW_BUILD_TESTS OFF CACHE BOOL "" FORCE)

FetchContent_MakeAvailable(glfw) # Dodanie biblioteki GLFW

add_executable(Renderer src/main.cpp src/glad.c) # Dodatnie biblioteki GLAD
target_include_directories(Renderer PRIVATE include)  

target_link_libraries(Renderer PRIVATE glfw OpenGL::GL)
```

### Wymagane biblioteki
- `OpenGL` - Framework do pracy graficznej
- `GLFW` - Biblioteka odpowiedzialna za zarządzanie okienkami na różnych systemach operacyjnych. Używana także w innych frameworkach np. Vulcan
- `GLAD` - "Łącznik" - znajduje adresy funkcji OpenGL i udostępnia je do użycia lda dewelopera

### Inicjalizacja projektu
1. Inicjalizacja GLFW:
```cpp
glfwInit();
glfwWindowHint(GLFW_CONTEXT_VERSION_MAJOR, 4);
glfwWindowHint(GLFW_CONTEXT_VERSION_MINOR, 1);
glfwWindowHint(GLFW_OPENGL_PROFILE, GLFW_OPENGL_CORE_PROFILE);
glfwWindowHint(GLFW_OPENGL_FORWARD_COMPAT, GLFW_TRUE);
```
2. Inicjalizacja funkcji OpenGL używając GLAD:
```cpp
if (!gladLoadGLLoader((GLADloadproc)glfwGetProcAddress))
{
	std::cout << "Failed to initialize GLAD" << std::endl;
	return -1;
}
```
3. Inicjalizacja okna:
```cpp
GLFWwindow *window = glfwCreateWindow(800, 600, "Hello World", NULL, NULL);
if (window == NULL)
{
	std::cout << "Failed to create GLFW windows" << std::endl;
	glfwTerminate();
	return -1;
}
glfwMakeContextCurrent(window);
glViewport(0, 0, 800, 600);
```
### Callbacks
Do okna GLFW można dodawać callbacki. Na przykład w celu dodania funkcjonalności na wydarzenie zmiany rozmiaru okna (resize) wykorzystamy następujący kod:
```cpp
void resizeCallback(GLFWwindow *window, int width, int height)
{
	glViewport(0, 0, width, height); // Zmienia dostępne miejsce do "rysowania"
}
glfwSetFramebufferSizeCallback(window, resizeCallback);
```
### Render loop
Klasyczną praktyką podczas tworzenia aplikacji będzie śledzenie inputów oraz renderowanie. W tym celu tworzymy render loop. Wygląda on następująco:
```cpp
while (!glfwWindowShouldClose(window))
{
	// INPUT
	if (glfwGetKey(window, GLFW_KEY_ESCAPE) == GLFW_PRESS) // Śledzenie czy klawisz ESCAPE został wciśnięty
		glfwSetWindowShouldClose(window, true);
		
	// RENDER
	glClearColor(137 / 256.0f, 207 / 256.0f, 240 / 256.0f, 1.0f); // Zmiana koloru tła na bby blue
	glClear(GL_COLOR_BUFFER_BIT);
	
	// Wywołanie eventów i zamiana bu
	glfwSwapBuffers(window);
	glfwPollEvents();
}
```
